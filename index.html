처음 한 번만 연결하면 됩니다

웹페이지는 보안상 PC 설정을 직접 바꿀 수 없어서, 작은 연결 파일이 버튼 신호를 받아 커서를 바꿉니다. 관리자 권한이 필요 없고 언제든 해제할 수 있습니다.

  1. 연결 파일 받기

    Windows 10, 11용 3KB짜리 파일 하나입니다. 크롬이 위험하다고 물으면 유지를 누르세요.

    연결 파일 받기 (1회)

  2. 더블클릭

    받은 Clickwee-Connect.bat을 더블클릭합니다. 파란 경고창이 뜨면 추가 정보, 실행을 누르세요. 창은 자동으로 닫힙니다.

  3. 끝, 이제 클릭만

    이 페이지로 돌아와 적용을 누르고, 브라우저가 열지 물으면 허용합니다. "항상 허용"을 체크하면 다음부터는 클릭 즉시 바뀝니다.
